About this demo

Bookish(Framer 템플릿)의 3D 책장과 틀을 우리 종이 카드로 다시 만들었어. 사이트 코드에서 숫자만 읽고(간격 3.4, 한 장 0.5초, 상세 0.9배, 아래에서 올라오는 등장), 코드는 새로 썼어.

휠: 한 장씩 · 카드를 끌면 줄이 밀리고, 빈 곳을 끌면 시점이 돌아서 뒷면이 보여 · 누르면 커지면서 오른쪽에 정보 · ← → 키, Esc로 닫기. 카드 모양(세로형 / 가로형 16:9 / 섞어서 — 카드마다 정한 모양)은 오른쪽 조절 패널에서.
