06

탈출 & 뒤집기

카드 세 장이 부채꼴로 모여 빠져나갔다가, 다시 날아와 한 줄로 뒤집혀.

스크롤해봐

이 데모에 쓴 기법

손에 쥔 부채꼴로 빠져나가기
나란히 있던 카드 세 장 중 바깥 두 장이 카드 폭의 0.9배만큼 가운데로 모이면서 −12° · 0° · 12°로 기울어, 손에 쥔 카드처럼 부채꼴이 돼. 그다음 아래로 가라앉으며 0.85배로 작아지고 뒤로 16° 누워. 세 장은 0.012만큼 시차를 두고 움직이는데, 맨 앞 라벤더가 제일 먼저 움직여서 뒤 카드가 오른쪽 위로 삐죽 나와. 카드 위에 배경색 막이 차올라서, 부채꼴로 모이는 도중(구간 33~53%)에 사라져. 그래서 가라앉고 눕는 뒷부분은 거의 안 보여.
다시 날아와 뒤집기
다음 구간(화면 3.5장 높이) 동안 무대가 화면에 붙어 있어. 카드는 위에서 0.2배로 작게, 앞으로 24° 숙인 채 가운데에 겹쳐 있다가, 덮여 있던 배경색 막이 구간 10~21%에 걷히면서 스르르 나타나고, 진행도 40%에 0.8배로 내려앉아. 여기서도 맨 앞 라벤더가 제일 먼저 움직여(원본 글 코드와 순서가 반대인데, 실제 사이트 영상이 이래서 영상을 따랐어). 55%에 잠깐 멈췄다가 75%까지 옆으로 벌어져 한 줄이 되면서 190° 뒤집히고, 82%에 180°로 살짝 되돌아오며 착 멈춰. 넘쳤다 돌아오는 10°가 손맛이야.
미니카드 진행 표시
오른쪽 아래 미니카드 세 장이 귀환 구간 진행도 1/3마다 한 장씩 아래에서 위로 차올라. 안 찬 부분은 35%만 보이고, 다 차면 4px 위로 올라와. (원본은 오른쪽 위인데, 여기선 조절 패널 자리라 아래로 옮겼어.)
둥실
카드마다 위아래로 3%씩 둥실거려. 한 번 오르내리는 시간은 1.5~2.5초 사이에서 매번 새로 뽑아서 자연스러워.
사라졌다 나타나기
원본 글에는 "막을 덮어 사라지게 한다"고만 있고 숫자가 없어서, 글에 실린 영상을 프레임마다 멈추고 카드 색 픽셀이 언제 옅어지는지 재서 구간을 정했어. 탈출은 33~53%, 귀환은 10~21%야. 처음엔 짐작으로 탈출 75~100%에 덮고 귀환엔 막을 안 줬더니, 원본에선 안 보이는 이동 경로(가라앉기, 아래에서 올라오기)가 다 보여서 움직임이 어설펐어.
스크롤 진행도
원본이 쓴 Locomotive Scroll v5의 계산식을 그대로 옮겼어. 첫 화면에 있는 탈출 구간은 스크롤 0에서 시작해 구간 아랫변이 화면 위에서 25% 내려온 순간 끝나고, 귀환 구간은 윗변이 화면 아래에서 5% 올라온 순간 시작해 아랫변이 화면 위에서 75% 내려온 순간 끝나. 이 0~1 값으로 멈춰둔 GSAP 타임라인을 감아.
만드는 방식
01~05와 달리 3D 엔진 없이, 웹페이지 요소를 CSS 3D로 돌려. 카드는 앞면·뒷면 두 장을 등 맞대 붙인 거라 뒤집으면 뒷면이 보여. 움직임은 원본과 같은 GSAP 키프레임이라 숫자가 그대로 옮겨졌어.

참고한 곳

숫자와 원리만 공부했고, 코드는 가져오지 않았어.

Built to Move (Codrops, Eduard Bodak): 탈출·귀환 키프레임 숫자, 미니카드 진행 표시, 둥실.

eduardbodak.com: 원본 포트폴리오 (지금은 디자인이 바뀌었어).

Locomotive Scroll: 스크롤 진행도 계산식.

GSAP: 키프레임 애니메이션.
