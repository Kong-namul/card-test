## 3. 원본에서 확인한 숫자 (06)

### 3.1 스크롤 진행도 (원본: Locomotive Scroll v5)

Locomotive v5 배포 코드(`locomotive-scroll@5.0.0/dist/locomotive-scroll.modern.mjs`)에서 계산식을 확인했다.
요소 위치 `top`, 높이 `height`, 화면 높이 `vh`, `data-scroll-offset="a, b"`(화면 높이 비율)일 때:

- 시작 = 요소가 첫 화면 안에 있으면(`top < vh`) **0**, 아니면 `top − vh + a·vh` (요소 윗변이 화면 아래에서 a만큼 올라온 순간)
- 끝 = `top + height − b·vh` (요소 아랫변이 화면 위에서 b만큼 내려온 순간)
- 끝 ≤ 시작이면 끝 = 시작 + 1
- 진행도 = (스크롤 − 시작) / (끝 − 시작), 0~1로 자름

| 구간 | offset | 원본 |
|---|---|---|
| 탈출(hero) | 0%, 25% | 첫 화면 안이라 0에서 시작 |
| 귀환(service) | 5%, 75% | 높이 350vh 컨테이너, 안쪽 sticky 100vh |

### 3.2 Part 01 — 탈출 (카드 3장)

- 타임라인을 멈춰두고(`paused`) 진행도로 감는다. 카드마다 `timeline.to(card, {keyframes}, index × 0.012)`.
- `position = index − 1` → −1, 0, 1
- 75% 지점: `x = −position × 카드폭 × 0.9`, `rotationZ = [−12, 0, 12]`
  → 바깥 두 장이 **가운데로 모이며** 손에 쥔 카드처럼 부채꼴이 된다 (벌어지는 게 아님, 영상 확인).
- 100% 지점: `y = (구간 높이 − 카드 높이) − [16, 32, 48]`, `scale 0.85`, `rotateX −16`
- `force3D: true`
- 카드 위에 배경색 막을 덮고 스크롤에 따라 불투명도를 올려 사라지게 한다 (원본은 숫자 없음 → 아래 4.3에서 정함).
- 둥실: `yPercent −3 → 3`, 시간 `random(1.5, 2.5)`초, `sine.inOut`, 무한 왕복, 왕복마다 시간 다시 뽑기(`repeatRefresh`).

### 3.3 Part 02 — 귀환 & 뒤집기

- `position = 2 − index − 1` → 1, 0, −1. 카드 자리는 한 줄(간격 카드폭 × 1.15)이고 index 0이 오른쪽.
  0% 지점 x가 자리 차이를 정확히 지워서 처음엔 세 장이 가운데에 겹쳐 있다. DOM 순서상 마지막(index 2, 라벤더)이 맨 앞.
- 키프레임 (카드마다 `index × 0.012` 시차):

| 지점 | 값 |
|---|---|
| 0% | `y = −0.75 × 화면높이 + 1`, `x = −position × 카드폭 × 1.15`, `scale 0.2`, `rotationZ [12, 0, −12]`, `rotateX 24` |
| 40% | `y "20%"`, `scale 0.8`, `rotationZ [5, 0, −5]`, `rotationY 0`, `rotateX 0` |
| 55% | `rotationY 0`, `y 0`, `x = 지금 x 그대로` |
| 75% | `x 0`, `rotationZ 0`, `rotationY −190`, `scale 1` |
| 82% | `rotationY −180` |
| 100% | `rotationZ 0` |

### 3.4 Part 2.1 — 미니카드 진행 표시

같은 귀환 구간 진행도 p로 미니카드 3장이 1/3씩 차오른다.
- i번째(0,1,2) 채움 = `clamp((p − 0.33·i) × 3, 0, 1)` (마지막 칸은 0.34 구간)
- 채운 부분 아래→위로 선명, 나머지는 35% 불투명 (`mask-image` 그라데이션)
- 올라옴: `4px × (1 − 채움)` → 다 차면 4px 위로

### 3.5 영상에서 잰 크기

- 탈출 카드 폭 ≈ 화면 폭 9%, 처음 간격 ≈ 카드폭 1.1배 (영상 02, 1440 기준 약 130px)
- 귀환 카드 폭 ≈ 화면 폭 24% (영상 04 마지막, 1440 기준 약 345px)
- 원본 페이지는 탈출과 귀환 사이에 검은 띠·문단 구간이 있다 (영상 01, 2~3초)

  - 패널 "사라짐 · 나타남" 폴더에 네 구간 값. 테스트 107개.
- 2026-11-22 사용자 "확정".

## 6. 07 마우스로 도는 카드 설계 (승인 2026-11-22 "좋아, 만들자")

### 6.1 원본에서 확인한 것

- 글 코드: 등장 `fromTo` `rotationZ 0 → 6`, `rotationY −90 → 0`, `y −4em → 0`, 1초 `elastic.out(1,0.75)` → 끝나면(`onComplete`) 마우스 따라가기 켬.
  따라가기는 매 프레임(`gsap.ticker`) `rotationY = 정규화 x × 200`, `rotationZ = 6 − min(|rotY|/180, 1) × 12`를 0.5초 `power2.out`으로 `gsap.to`.
  정규화 x = (마우스 x − 화면 가운데) / 화면 가운데. 무대를 나가거나 메뉴 위에 올라가면 `rotationX 0, rotationY 0, rotationZ 6`, 1.5초 `elastic.out(1,0.75)`.
  마우스·호버가 되는 기기 + 동작 줄이기 꺼짐일 때만 켬. 반사는 "카드를 복제하고 그라데이션·backdrop-filter를 덮어 반대 값으로 움직인다"(숫자 없음, 코드의 `rotationZMirror = −6 + 진행 × 12`).
- 영상 07·08·09번: 카드 폭 ≈ 화면 폭 9%, 큰 제목 두 줄 중 아랫줄을 카드가 절반쯤 가리며 앞에 섬. 앞면 하얀 가격표, 뒷면 그림(끝까지 돌리면 보임).
  등장 때 원근이 보임(옆으로 선 카드가 사다리꼴). 반사는 카드 바로 아래 카드 높이 약 15%만 흐릿하게 보이는 잔상.

### 6.2 결정

- 카드: 앞면 종이 무지(`--card-paper`), 뒷면 라벤더(`--card-lavender`). 새 색 없음. 카드 모양은 `shared/dom-card.css`.
- 화면: 가운데 큰 제목 "마우스로 / 도는 카드"(72px, 폰 48px, 흰색) + 카드가 아랫줄을 절반(줄 높이의 1/2) 가리며 앞에. 왼쪽 아래 캡션(07 · 설명 · 조작법).
- 카드 폭 `clamp(110px, 9vw, 180px)`.
- 등장 `y −64px` (원본 −4em, 16px 기준).
