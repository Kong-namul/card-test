# 11 책 캐러셀 — Bookish 틀 그대로 (설계)

2026-11-25 · 사용자: "https://boookish.framer.website 이 스타일도 만들어줄 수 있어? 옵션 두 개, 세로형·가로형(16:9)", "누를 때 커지는 것까지, 텍스트까지 다 스타일 가지고 와줘", "이 사이트의 틀은 거의 그대로 쓸 일이 있어", "그냥 저거를 똑같이 만든다고 생각해줘".
선택: 움직임 4가지 전부(가로 줄·휠 한 장씩 / 누르면 커지고 정보 패널 / 끌면 시점이 돌아 뒷면 / 등장), 카드는 **우리 종이 카드 그대로**, 글자·색은 **레퍼 세트를 공통 파일에 추가**, 세로형·가로형은 **한 페이지 + 조절 패널에서 바꾸기**(기본 세로형).

## 1. 레퍼런스와 지킬 것

- Bookish — 3D Interactive Book Framer Template (Framer 유료 템플릿, "Buy Template"). 3D는 Three.js 0.136 캔버스 하나, 틀(왼쪽 띠·버튼·소개 패널)은 Framer 페이지.
- 실제 스크립트(`shared-lib.*.mjs`의 InfiniteBookShelf 컴포넌트, 사이트가 넘긴 설정값)에서 원리·숫자만 읽었다. **코드는 복사하지 않고 우리 코드로 다시 쓴다.**
- 사이트 것인 이름·문구·이미지(BOOKISH, "DEIGNED FOR THE LOVE OF BOOKS", 큐레이터 소개·사진, 책 표지)는 쓰지 않는다 → 우리 이름·예시 문구·빈 자리로. 실제 서비스에 틀을 그대로 쓸 땐 템플릿 구매가 확실하다고 사용자에게 알렸다.

## 4. 공통 파일에 더할 것 (사용자 허락: "레퍼 세트 그대로 추가")

- `shared/tokens.css` "Bookish 세트": 글꼴 `--font-bk-title`(Anybody) · `--font-bk-mono`(Chivo Mono) · `--font-bk-ui`(Inter) · `--font-bk-text`(General Sans), 크기 `--text-10·11·12·16·26·42`와 짝 줄간격, 색 `--bk-neon` #ECFF5C · `--bk-side` #2B2B29 · `--bk-stage` #171614 · `--bk-line` rgba(244,241,234,0.28). 기존 값은 그대로 → 다른 데모 영향 없음. `?v=` 올림.

## 5. 카드 (3D)

- 공통 종이 카드(`card-geometry`·`card-material`·질감 패널), 휨 0, 두께 없음. 뒷면은 공통 재질 뒷면(시점을 돌리면 보임).
- **세로형**(기본): 높이 3.2(레퍼 책 높이), 폭 3.2 × 345/490 ≈ 2.25, 간격 3.4.
- **가로형 16:9**: 폭 4.4 · 높이 2.475, 간격 = 폭 + 1.2(세로형 틈 1.2와 같게) = 5.6. 회전·깊이는 r을 간격 비율(3.4/5.6)로 줄여 계산해서 세로형과 같은 장 수만큼 떨어진 카드가 같은 각도.
- 카드 10장, 예시 내용은 `demos/11-books/cards-data.js` 한 파일(제목·이름·연도·분류·설명)에 모아 바꾸기 쉽게.
- 조절 패널: 형태(세로형/가로형), 간격, 질감 폴더. 상세 패널·버튼은 화면에.

## 8. 확인 뒤 바뀐 것 (사용자 피드백, 2026-11-25)

- "반응형이 안 된 것 같아" → 레퍼 기준점 확인: 데스크톱 1200px 이상 · 태블릿 810~1199px(데스크톱과 같은 값) · 폰 809px 이하(mobile 변형). 사용자 요청 "크기·위치·뾰족만 수정" → 세로형 카드를 레퍼 책 크기 그대로 **2.2 × 3.2**, 모서리 **0(뾰족)** 이 기본, 폰에서 카드 줄 **1.2 위로**(`narrowListOffsetY`). (375×812에서 잰 캔버스 −103px은 스크롤된 상태로 잰 실수라 뺐다. 새로 열어 재니 0)
- "눌렀을 때 카드가 이상한 데 가" → 사용자 창이 719px라 폰 모드였고, 레퍼도 폰에선 상세 카드를 오른쪽 아래(1.45, −3.35)로 보내 잘리게 둔다(같은 크기에서 레퍼와 위치 일치 확인). 사용자 선택 "옵셔널하게, 기본은 가운데" → 패널 형태 > "폰에서 누르면": **가운데(기본)** = 상세 글(닫기 버튼) 아래 남는 자리 한가운데, 가로 가운데, 자리가 모자라면 카드를 줄임(최소 0.3배, `centeredDetail`) / **레퍼대로** = 오른쪽 아래.
- 폰에서 남은 차이(이번엔 안 고침): 왼쪽 아래 제목 크기(레퍼 18px), 상세 제목(레퍼 32px), 조절 패널이 왼쪽 띠를 가림. → 제목 크기는 아래에서 고침.
- "세로형과 가로형이 섞인 것도 있을 거라 옵션 하나 추가" → 패널 형태 > 카드 모양에 **섞어서 (카드마다)**. 카드 내용(`cards-data.js`)의 `shape: 'landscape'`인 카드만 가로형(예시 2·5·8번째), 나머지 세로형. 카드 사이 **틈은 모양 상관없이 1.2**(패널 "카드 사이 틈", 예전 "카드 간격" 대신) → 세로형만이면 간격 3.4, 가로형만이면 5.6으로 예전과 같다. 회전·깊이는 줄 평균 간격으로(모든 카드가 같은 곡면 위), 크기·밝기는 가운데 쪽 이웃까지 거리로(바로 옆 카드는 늘 0.93배·밝기 0.35). 휠·끌기·스냅은 가장 가까운 카드로(`layoutRow`·`rowIndexAt`·`rowSnapTarget`). 모양마다 카드 묶음·재질 하나씩(둥근 모서리가 카드 크기를 알아야 해서), 질감 패널 값은 두 재질에 같이.
- "상세에서 가로든 세로든 잘리면 안 돼, 좌우·위아래 여백에 맞게" → `fitDetail`: 카드가 들어갈 빈 칸 안 여백 24px 안쪽에 다 들어가게. 바라는 자리·크기(넓은 화면은 레퍼 왼쪽 0.8·0.9배)가 들어가면 그대로, 삐져나가면 안으로 밀고, 그래도 크면 줄인다(최소 0.3배). 1440×900 세로형은 레퍼 자리 그대로, 가로형은 패널에서 24px 떨어지게 조금 왼쪽으로.
- "작아지면 위아래로, 카드 위 · 글 아래" → 사용자 선택 "폰 + 세로 태블릿": 폭 809px 이하는 늘, 810~1199px는 세로로 들었을 때(`orientation: portrait`)만 **위아래**(JS가 `.is-stack`). 글은 아래에 붙고(최대 60%, 넘치면 안에서 스크롤), 카드는 네온 버튼·조절 패널 제목줄 아래부터 글 위까지 빈 칸 한가운데. 810~1199px 가로·1200px 이상은 예전처럼 좌우. 폰 옵션은 **카드 위 · 글 아래(기본)** / **레퍼대로**(글 위, 카드 오른쪽 아래로 가서 잘림 — 레퍼 그대로).
- 확인(카드 픽셀 테두리): 375×812 가로형 23~312px(캔버스 335) · 세로형 위아래 빈 칸 134~325px 안, 820×1180 위아래 좌우 64px, 1180×820 좌우 배치 패널 왼쪽 24px, 1440×900 세로형 레퍼 그대로·가로형 패널 24px 앞.
